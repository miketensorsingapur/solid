# Спецификация: разбор и расчёт

Веб-приложение (React + Vite): загружает текстовый файл спецификации из CAD, показывает его таблицей,
считает материалы и раскладывает позиции по сборкам и участкам. Всё работает в браузере, файл никуда не отправляется.

## Что умеет

1. **Выбор файла** с устройства (`.txt` / `.tsv` с разделителем табуляция, также `.csv`). Кодировка определяется сама (UTF-8, Windows-1251, UTF-16).
2. **Исходная таблица.** Названия колонок берутся из первой строки файла. Сортировка по любой колонке (клик по заголовку: по возрастанию → по убыванию → сброс), числа сортируются как числа, пустые значения всегда внизу. Кнопка «Колонки» скрывает ненужные.
3. **Рассчитать.** Новая таблица по материалам: одинаковые артикулы объединяются, считаются общая масса, площадь материала и площадь покраски (+ суммарная длина заготовок и итоговая строка).
4. **Посмотреть участки.** Таблицы с деталями по группам, два режима:
   - *По сборкам* — строка «СБ», а ниже её детали до следующей сборки;
   - *По участкам* — все строки, сгруппированные по колонке «Участок» (Сварочный, Гибка, Металл, Лазер, …).

## Как считается

- В расчёт входят только детали. Сборки («СБ») — контейнеры, их масса и площадь уже содержатся в деталях.
- Количество детали = её количество × количество сборок, в которые она входит (вложенность определяется по номерам позиций: `1.2` входит в `1`).
- Артикулы материала сравниваются без учёта регистра, пробелов и вида буквы «х» (латинская / русская).
- **Масса** — «Масса, г» (на одну штуку) × количество.
- **Площадь материала.** Труба: периметр сечения по размерам из названия (`Труба 40x25x2` → 2·(40+25) мм) × длина заготовки. Лист (`Лист 3 мм`): «Площадь поверхности» / 2, то есть площадь заготовки с одной стороны. Остальное: «Площадь поверхности» из файла, если она указана.
- **Площадь покраски** — только для деталей в сборках с покрытием. Труба: наружная поверхность. Лист и прочее: вся «Площадь поверхности» детали.
- Если у листа нет площади в файле, она оценивается по массе (сталь, 7,85 г/см³) — приложение об этом предупреждает.

Формулы лежат в `src/lib/calc.ts`, их легко поменять.

## Запуск

```bash
npm install
npm run dev           # режим разработки
npm run build         # Vite: dist/index.html одним файлом (vite-plugin-singlefile)
npm run build:single  # то же без Vite, только esbuild: dist/index.html
npm test              # проверка разбора и расчётов на samples/
```

Готовый `dist/index.html` лежит в репозитории: его можно открыть двойным кликом, сервер не нужен.
Файл в репозитории собран командой `npm run build:single`.

## Структура

```
src/lib/parse.ts      чтение файла, разбор колонок и вложенности
src/lib/calc.ts       материалы, объединение и расчёты
src/lib/sections.ts   группировка по сборкам и по участкам
src/components/       таблица с сортировкой, выбор колонок, экраны
scripts/check.ts      проверки на примере из samples/
scripts/build-single.mjs  сборка в один index.html через esbuild
```

UI: [Headless UI](https://headlessui.com/) + [react-icons](https://react-icons.github.io/react-icons/) и собственные стили (`src/styles.css`).
